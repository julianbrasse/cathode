Engineered for Television Remotes

No air-mouse or trackpad required. Built from the ground up for standard D-Pad directional controls.

Back-to-Navbar Architecture

Pressing BACK while web browsing never accidentally closes the app. It summons the navigation bar. Dismiss the bar instantly with UP or DOWN, or press BACK inside the navbar to step backward through web history.

Intelligent Modal Edge Scrolling

When the cursor hovers inside any popup, modal card, or iframe (such as Google's 9-dot app drawer or cookie sheets), edge scrolling automatically clamps to the modal's boundaries. Pushing against the modal edge scrolls the inner container smoothly without traveling to TV bezels.

Unified Glass Reticles

Dynamic scroll reticles match the exact 3dp drop shadow, white outline, and translucent frosted glass styling of the main cursor. Engineered to deliver razor-sharp contrast whether hovering over dark cinema UI, bright white document backgrounds, or colorful video thumbnails.

Fluid 60 FPS Scrolling

Eliminates harsh scroll jumping. Web pages and overflow containers leverage Chromium's hardware-composited smooth scrolling engine, paired with targeted touch fling events for isolated cross-origin iframes.

Direct D-Pad Focus & Outline

When the navigation bar is open, every button and the URL search field are fully focusable with crisp 2.5dp high-contrast outlines. An embedded one-click [ ✕ ] button clears the input for fast TV typing.

Dedicated Exit Dialog & Hygiene

Features an explicit Exit button on the bar with a native TV confirmation dialog. On exit or background pause, Cathode stops network connections, trims memory caches, unregisters handlers, and destroys the WebView cleanly.

Technical Setup & Engineering

Why Cathode outperforms conventional web browsers on resource-constrained TV hardware.

Zero-Dependency Standalone Footprint

Most TV browsers bundle heavy Chromium forks, third-party ads, tracking SDKs, or multi-megabyte UI frameworks that consume hundreds of megabytes of RAM. Cathode is compiled purely against the native Android platform SDK. By relying on Android's system-managed Chromium WebView, Cathode stays under 150 KB, boots instantly, and inherits all OS-level security and GPU-rendering updates automatically.

Hybrid Event Dispatching

Television browsers frequently struggle to scroll inside complex iframes (like Google's app drawer) or modern single-page applications. Cathode implements a hybrid dispatch model:

  • Native DOM Smooth Scroll: Targets the deep element or document under the cursor via window.scrollBy({top: dy, behavior: 'smooth'}), avoiding compositor thread locks.
  • Targeted Touch Drag Gestures: When hovering inside cross-origin iframes where JavaScript DOM access is restricted by the Same-Origin Policy, Cathode dispatches synthetic touch drag events directly at the cursor coordinates.
  • Hardware Scroll Events: Injects hardware mouse-wheel ACTION_SCROLL events with precise vertical axis deltas.

Proactive Memory Management

Television devices typically operate with constrained RAM (1.5GB to 2.5GB shared with OS and video decoders). Cathode implements:

  • onTrimMemory(TRIM_MEMORY_MODERATE): Flushes WebView caches and background DOM bitmaps whenever the TV OS experiences memory pressure.
  • Automatic IME Hiding: Proactively dismisses the virtual keyboard when navigating back to web content or closing dialogs to free window manager resources.
  • Complete Lifecycle Teardown: onDestroy() halts active network threads, unregisters message loops, loads about:blank, and explicitly calls webView.destroy().

Installation & Sideloading

Install on any Android TV, Google TV, or Android TV Emulator in seconds via ADB.

1. Connect to Android TV via ADB

adb connect <YOUR-TV-IP>:5555

2. Install Cathode APK

adb install -r Cathode.apk

3. Launch Directly

adb shell am start -n com.cathode.browser/.MainActivity
