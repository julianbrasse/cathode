Why "Cathode"?

The name pays homage to the Cathode Ray Tube (CRT) -- the foundational technology that brought the very first television images to life. In a CRT, a focused electron beam directly scans across a phosphor screen with zero abstraction and instant physical response.

Cathode brings that direct, zero-overhead philosophy to modern TV web browsing. Instead of sluggish mobile emulators, you get a razor-sharp, hardware-accelerated 60px virtual cursor and direct D-Pad control. Pure speed, precision navigation, zero bloat.

Fast Installation

Install on any Android TV or Google TV device in seconds.

Method 1: Direct ADB Install (Recommended)

If your TV has Developer Options and Network Debugging enabled, install directly over Wi-Fi:

adb connect <TV_IP_ADDRESS>:5555 && adb install -r Cathode.apk

Method 2: Sideload via USB or Send Files to TV

Download Cathode.apk, transfer it to your TV using a USB drive or the "Send Files to TV" app, and open it with any TV file manager to install.
